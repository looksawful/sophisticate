# Storybook

Изолированный каталог реальных компонентов Sophisticate.

Команды: `npm ci`, `npm run storybook`, `npm run build-storybook`.

Истории: `ProcessingOverlay` (Preparing / Processing / Finalizing / Complete); `TimelineTrimHandles` (клавиатурное управление).

Проверено 2026-11-07: `npm run build-storybook` — успешно; `npm run typecheck` — успешно.

GitBook: https://app.gitbook.com/o/vNK58vV2S63vxervMh3G/sites/site_SaA3i (не опубликован).

Моки и Storybook не заменяют браузерные тесты FFmpeg и экспортных ограничений.
